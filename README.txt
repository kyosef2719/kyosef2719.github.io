# Movie Correlation Project

## Project Overview
This project explores a dataset of movies to find which variables (like budget, company, or score) have the highest correlation with gross revenue.

## Tools Used
* **Python** (Pandas, NumPy, Seaborn, Matplotlib)
* **Jupyter Notebook**

## Key Findings
* Budget and Gross Revenue have a high correlation.
* Votes and Gross Revenue also show a significant relationship.
* Interestingly, the 'Score' (rating) of a movie had a lower correlation with revenue than expected.

## How to Run
1. Download the `movies.csv` file.
2. Open the `movie_analysis.ipynb` in Jupyter Notebook or VS Code.
